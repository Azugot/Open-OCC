# OOC Story App Handoff Archive

This ZIP contains the agreed project specification and implementation handoff for a private, self-hosted AI story application.

Read in this order:

1. `IMPLEMENTATION-HANDOFF.md` — instructions for the implementing Codex agent.
2. `OOC-Story-App-Conversation-and-Specification.md` — project decisions, architecture, acceptance criteria, and substantive conversation record.
3. `Lumencia-Research-and-Clean-Room-Blueprint.md` — research context and an original academy template for testing/new campaigns.

The app will use React/Vite, ASP.NET Core, PostgreSQL, Docker Compose, a server-side `.env` provider configuration, and an agent-assisted campaign migration flow.
